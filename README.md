
# WD-Activity-Based-Learning

## Web Development Activity-Based Learning Project

This project contains three web development case studies created using **HTML and CSS**. The aim is to practise webpage design, HTML elements, CSS styling, navigation links and layout techniques.

## Case Studies

### 1. Personal Portfolio Website
A personal portfolio webpage that introduces a student and displays their education, skills, interests and contact information.

**Features:**
- Personal introduction and profile section
- Navigation links to different sections
- Education and learning goals
- Skills displayed using styled tags
- Interests displayed using cards
- Contact information section
- Hover effects and responsive layout

### 2. College Information and Admissions Website
A college website designed to provide information about courses, campus facilities and admissions.

**Features:**
- College name and welcome banner
- Navigation menu
- About the college section
- Course information cards
- Campus facilities section
- College statistics
- Admissions section with an email link
- Contact information

### 3. Bakery and Cake Shop Website
A bakery website that displays products, prices, special offers and contact information.

**Features:**
- Bakery welcome banner
- Navigation menu
- Product cards for cakes, cupcakes and cookies
- Product descriptions and prices
- Today's special offer
- Email enquiry links for products
- Hover effects and attractive styling

## Technologies Used

- **HTML5** — To create the structure and content of webpages.
- **CSS3** — To style webpages and improve their appearance.

## HTML and CSS Concepts Practised

- Headings and paragraphs
- `div`, `header`, `nav` and `footer`
- Links using the `a` tag
- `class` and `id` attributes
- Text and background colours
- Padding and margins
- Borders and rounded corners
- Box shadows
- Flexbox layouts
- Hover effects
- Basic responsive design

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open any of the three `.html` files.
4. Run the file using Live Server or open it directly in a web browser.
5. Use the navigation links to explore the webpage sections.
